# Third-party notices

Python dependencies are installed through pip rather than copied into the archive.
Their package metadata contains their respective licenses; versions are listed in
`requirements.txt` and `requirements-dev.txt`.

The frontend uses project HTML and CSS and bundles no third-party browser libraries.
The offline snapshots contain sourced VIT profile observations and OpenAlex
publication metadata. Source URLs and evidence are retained with the records.
This collection is not an official university dataset. See `docs/PROJECT_REPORT.md`
for collection methods, attribution and limitations.
